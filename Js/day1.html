Day 1: Introduction to JavaScript

What is JavaScript?

JavaScript is a programming language used to build interactive web applications and dynamic websites.

With JavaScript:

  • Buttons work
  • Forms validate
  • Data loads dynamically
  • Animations run

Example Interactions:

  • Form validation
  • Dropdown menus
  • Sliders
  • API data loading
Where JavaScript Runs

JavaScript mainly runs in:

Browser

  • Chrome
  • Edge
  • Safari
  • Firefox
How to Add JavaScript to HTML

There are 3 ways.

Browser

  • Method 1 - Inline JavaScript (Not recommended)
  • Method 2 - Internal JavaScript
  • Method 3 - External JavaScript (Best Practice)
JavaScript Console

console.log("Hello JavaScript");
