Day 5: Control Flow

Conditional Statements

Control flow allows your program to make decisions and execute different code based on conditions.

if Statement:

if (condition) {
    // code to execute if condition is true
}

let age = 18;
if (age >= 18) {
    console.log("You are an adult");
}

if-else Statement:

if (condition) {
    // code if true
} else {
    // code if false
}

let temperature = 25;
if (temperature > 30) {
    console.log("It's hot!");
} else {
    console.log("It's not too hot");
}
else-if Statements

Use else-if to check multiple conditions in sequence. 

if (condition1) {
    // code for condition1
} else if (condition2) {
    // code for condition2
} else {
    // code if none of the above
}

let score = 85;
if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F");
}
Ternary Operator

A shorthand way to write simple if-else statements. 

// condition ? valueIfTrue : valueIfFalse
let age = 20;
let status = age >= 18 ? "adult" : "minor";
console.log(status); // "adult"

// Multiple operations
let message = age >= 18 ? "Welcome!" : "Access denied";
console.log(message);
Switch Statement

Switch statements are useful when you have many conditions to check against the same variable. 

switch (expression) {
    case value1:
        // code
        break;
    case value2:
        // code
        break;
    default:
        // code
}

let day = "Monday";
switch (day) {
    case "Monday":
        console.log("Start of work week");
        break;
    case "Friday":
        console.log("TGIF!");
        break;
    case "Saturday":
    case "Sunday":
        console.log("Weekend!");
        break;
    default:
        console.log("Regular day");
}
Loops

Loops allow you to execute code repeatedly.

for Loop:

for (initialization; condition; increment) {
    // code to repeat
}

for (let i = 0; i < 5; i++) {
    console.log("Count: " + i);
}

while Loop:

while (condition) {
    // code to repeat
}

let count = 0;
while (count < 5) {
    console.log("Count: " + count);
    count++;
}

do-while Loop:

do {
    // code to repeat (executes at least once)
} while (condition);

let num = 0;
do {
    console.log("Number: " + num);
    num++;
} while (num < 3);
Loop Control Statements

Special statements to control loop execution.

break:

for (let i = 0; i < 10; i++) {
    if (i === 5) {
        break; // exits the loop
    }
    console.log(i);
}

continue:

for (let i = 0; i < 10; i++) {
    if (i % 2 === 0) {
        continue; // skips to next iteration
    }
    console.log(i); // only odd numbers
}
