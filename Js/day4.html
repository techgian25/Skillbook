Day 4: Arrays and Objects

Arrays

Arrays are ordered collections of values. They can store multiple values in a single variable.

Creating Arrays:

// Array literal
let fruits = ["apple", "banana", "orange"];

// Empty array
let emptyArray = [];

// Array with mixed types
let mixed = [1, "hello", true, null];

Accessing Array Elements:

let fruits = ["apple", "banana", "orange"];

console.log(fruits[0]); // "apple"
console.log(fruits[1]); // "banana"
console.log(fruits.length); // 3
Array Methods

Arrays have built-in methods for common operations:

Common Methods:

  • push() - Add elements to the end
  • pop() - Remove the last element
  • shift() - Remove the first element
  • unshift() - Add elements to the beginning
  • slice() - Extract a portion of the array
  • splice() - Add/remove elements at any position
let fruits = ["apple", "banana"];

fruits.push("orange"); // ["apple", "banana", "orange"]
fruits.pop(); // removes "orange", returns ["apple", "banana"]
fruits.unshift("grape"); // ["grape", "apple", "banana"]
fruits.shift(); // removes "grape", returns ["apple", "banana"]
Objects

Objects are collections of key-value pairs. They represent real-world entities with properties and methods.

Creating Objects:

// Object literal
let person = {
    name: "John",
    age: 30,
    isStudent: false
};

// Empty object
let emptyObject = {};

// Constructor
let car = new Object();
car.make = "Toyota";
car.model = "Camry";

Accessing Object Properties:

let person = {
    name: "John",
    age: 30
};

console.log(person.name); // "John"
console.log(person["age"]); // 30

// Adding properties
person.email = "john@example.com";

// Deleting properties
delete person.age;
Object Methods

Objects can have methods (functions as properties): 

let person = {
    name: "John",
    age: 30,
    greet: function() {
        return "Hello, my name is " + this.name;
    },
    birthday: function() {
        this.age += 1;
        return "Happy birthday! You are now " + this.age;
    }
};

console.log(person.greet()); // "Hello, my name is John"
console.log(person.birthday()); // "Happy birthday! You are now 31"
Iterating Over Arrays and Objects

You can loop through arrays and objects to access their elements:

Array Iteration:

let fruits = ["apple", "banana", "orange"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

// Or using forEach
fruits.forEach(function(fruit) {
    console.log(fruit);
});

Object Iteration:

let person = { name: "John", age: 30 };

for (let key in person) {
    console.log(key + ": " + person[key]);
}

// Or using Object.keys
Object.keys(person).forEach(function(key) {
    console.log(key + ": " + person[key]);
});
