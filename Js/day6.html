Day 6: DOM Manipulation

What is the DOM?

The Document Object Model (DOM) is a programming interface for HTML and XML documents. It represents the page as a tree of objects that you can manipulate with JavaScript.

DOM Tree Structure:

  • document - The root of the DOM tree
  • html - The HTML element
  • head and body - Child elements of html
  • All other HTML elements form the tree structure
Selecting Elements

There are several methods to select DOM elements:

getElementById:

const element = document.getElementById('myId');

getElementsByClassName:

const elements = document.getElementsByClassName('myClass');
// Returns HTMLCollection

getElementsByTagName:

const paragraphs = document.getElementsByTagName('p');
// Returns HTMLCollection

querySelector:

const element = document.querySelector('#myId');
const element = document.querySelector('.myClass');
const element = document.querySelector('div > p');

querySelectorAll:

const elements = document.querySelectorAll('.myClass');
// Returns NodeList
Changing Content

You can change the content and attributes of DOM elements:

innerHTML:

const div = document.querySelector('#myDiv');
div.innerHTML = '
New content with HTML
';

textContent:

const div = document.querySelector('#myDiv');
div.textContent = 'New text content (HTML tags are escaped)';

Changing Attributes:

const img = document.querySelector('img');
img.src = 'new-image.jpg';
img.alt = 'New alt text';

// Or using setAttribute
img.setAttribute('src', 'new-image.jpg');
img.setAttribute('alt', 'New alt text');
Changing Styles

You can modify CSS styles using the style property: 

const element = document.querySelector('#myElement');

// Single style property
element.style.color = 'red';
element.style.fontSize = '20px';
element.style.backgroundColor = 'yellow';

// Multiple styles
element.style.cssText = 'color: red; font-size: 20px; background: yellow;';

// Adding/removing classes
element.classList.add('highlight');
element.classList.remove('oldClass');
element.classList.toggle('active');
Creating and Adding Elements

You can create new elements and add them to the DOM:

Creating Elements:

// Create a new element
const newDiv = document.createElement('div');
newDiv.textContent = 'Hello World!';
newDiv.className = 'my-class';

// Create a text node
const textNode = document.createTextNode('Some text');

// Create an element with attributes
const newImg = document.createElement('img');
newImg.src = 'image.jpg';
newImg.alt = 'An image';

Adding Elements to DOM:

const parent = document.querySelector('#parent');
const newElement = document.createElement('p');
newElement.textContent = 'New paragraph';

// Append as last child
parent.appendChild(newElement);

// Insert before another element
const reference = document.querySelector('#reference');
parent.insertBefore(newElement, reference);

// Using modern methods
parent.append(newElement); // Can append multiple
parent.prepend(newElement); // Add as first child
Removing Elements

You can remove elements from the DOM: 

const element = document.querySelector('#toRemove');

// Remove child from parent
const parent = element.parentNode;
parent.removeChild(element);

// Modern way - remove directly
element.remove();

// Remove all children
const container = document.querySelector('#container');
while (container.firstChild) {
    container.removeChild(container.firstChild);
}
Traversing the DOM

You can navigate through the DOM tree: 

const element = document.querySelector('#myElement');

// Parent
const parent = element.parentNode;
const parentElement = element.parentElement;

// Children
const firstChild = element.firstChild;
const lastChild = element.lastChild;
const allChildren = element.children; // Only element children

// Siblings
const nextSibling = element.nextSibling;
const nextElementSibling = element.nextElementSibling;
const prevSibling = element.previousSibling;
const prevElementSibling = element.previousElementSibling;
