Day 3: HTML Forms

Form Basics

Forms allow users to input and submit data to a server:

Form Elements:

  • <form> - Container for form controls
  • <input> - Input field
  • <textarea> - Multi-line text area
  • <label> - Label for form fields
Input Types

Different input types for different data:

Common Input Types:

  • text - Single line text
  • email - Email address
  • password - Hidden password
  • number - Numeric input
  • checkbox - Multiple selections
  • radio - Single selection
Form Attributes

Important form attributes:

Key Attributes:

  • action - Where form data is sent
  • method - GET or POST
  • name - Field name for submission
  • placeholder - Sample text in input
  • required - Field is mandatory
Form Controls

Additional form elements:

More Elements:

  • <button> - Clickable button
  • <select> - Dropdown menu
  • <option> - Menu option
  • <fieldset> - Group form elements
Learning Outcomes
  • Create HTML forms
  • Use proper input types
  • Implement form validation
  • Handle form submission
