Day 12: CSS Animations & Transitions

CSS Transitions

Smooth changes between states:

Transition Properties:

  • transition-property - What to animate
  • transition-duration - How long
  • transition-timing-function - Animation curve
  • transition-delay - Delay before start
Timing Functions

Animation speeds:

Common Functions:

  • ease - Slow start and end
  • ease-in - Slow start
  • ease-out - Slow end
  • linear - Constant speed
CSS Animations

Create complex animations:

Animation Properties:

  • @keyframes - Define animation stages
  • animation-name - Keyframes name
  • animation-duration - Length
  • animation-iteration-count - Repeat times
Keyframe Syntax

Define animation stages:

Example:

  • 0% { opacity: 0; }
  • 50% { opacity: 0.5; }
  • 100% { opacity: 1; }
Learning Outcomes
  • Create smooth transitions
  • Define animations
  • Use keyframes
  • Control animation timing
