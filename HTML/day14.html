Day 14: CSS Variables & Functions

CSS Variables

Reusable values in CSS:

Variable Basics:

  • Define: --primary-color: #0088cc;
  • Use: var(--primary-color)
  • Scope: Root or local
  • Fallback: var(--color, blue)
CSS Functions

Built-in CSS functions:

Common Functions:

  • calc() - Mathematical calculations
  • url() - Load resources
  • rgb()/rgba() - Color values
  • linear-gradient() - Color gradients
calc() Function

Perform calculations:

Examples:

  • width: calc(100% - 20px);
  • height: calc(100vh - 60px);
  • Combine units: px, %, em, etc.
Gradient Functions

Create color gradients:

Types:

  • linear-gradient(direction, colors)
  • radial-gradient(shape, colors)
  • conic-gradient() - Rotating colors
Learning Outcomes
  • Create CSS variables
  • Use calc() function
  • Build gradient backgrounds
  • Create dynamic themes
