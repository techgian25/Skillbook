Day 2: HTML Elements & Attributes

Common HTML Elements

HTML provides many elements for different types of content:

Text Elements:

  • <strong> - Bold text (semantic)
  • <em> - Italic text (semantic)
  • <u> - Underlined text
  • <mark> - Highlighted text
Links and Images

Creating interactive content with links and media:

Key Elements:

  • <a href="url"> - Anchor tag for links
  • <img src="path" alt="text"> - Image tag
  • <video> - Video content
  • <audio> - Audio content
Container Elements

Use containers to organize content:

Important Containers:

  • <div> - Generic block container
  • <span> - Generic inline container
  • <section> - Thematic grouping
  • <article> - Independent content
Important Attributes

Attributes provide additional information:

Common Attributes:

  • href - URL destination for links
  • src - Source path for images
  • alt - Alternative text for images
  • title - Hover tooltip text
  • class - CSS class name
  • id - Unique identifier
Learning Outcomes
  • Use text formatting elements
  • Create links and add images
  • Organize content with containers
  • Apply attributes correctly
