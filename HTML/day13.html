Day 13: CSS Advanced Selectors

Combinators

Combine selectors for precision:

Types:

  • Descendant: div p (all p inside div)
  • Child: div > p (direct children)
  • Adjacent: h1 + p (right after)
  • General sibling: h1 ~ p (siblings)
Pseudo-classes

Target element states:

Common Pseudo-classes:

  • :hover - Mouse over
  • :focus - Element focused
  • :nth-child() - Nth element
  • :first-child, :last-child
Pseudo-elements

Create virtual elements:

Common Pseudo-elements:

  • ::before - Insert before
  • ::after - Insert after
  • ::first-line - First line
  • ::selection - Selected text
Attribute Selectors

Target by attributes:

Examples:

  • [type="text"] - Attribute value
  • [href] - Has attribute
  • [href^="https"] - Starts with
  • [class*="box"] - Contains
Learning Outcomes
  • Use CSS combinators
  • Apply pseudo-classes
  • Use pseudo-elements
  • Create precise selectors
