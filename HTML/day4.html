Day 4: Semantic HTML

What is Semantic HTML?

Semantic HTML uses meaningful tags that describe content, improving accessibility and SEO:

Semantic vs Non-semantic:

  • Semantic: <header>, <nav>, <article>
  • Non-semantic: <div>, <span>
Semantic Layout Elements

Structure your page with these semantic elements:

Layout Elements:

  • <header> - Page or section header
  • <nav> - Navigation menu
  • <main> - Main content area
  • <aside> - Sidebar content
  • <footer> - Page or section footer
Content Semantic Elements

Mark up content meaningfully:

Content Elements:

  • <article> - Self-contained content
  • <section> - Thematic grouping
  • <figure> - Self-contained illustration
  • <figcaption> - Figure caption
Benefits of Semantic HTML

Why semantic HTML matters:

Advantages:

  • Improved accessibility for screen readers
  • Better SEO for search engines
  • Cleaner, more maintainable code
  • Better browser support
Learning Outcomes
  • Understand semantic HTML importance
  • Use semantic layout elements
  • Mark up content semantically
  • Improve accessibility
