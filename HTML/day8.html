Day 8: CSS Layout & Display

Display Property

Controls how elements are rendered:

Display Values:

  • block - Full width, line breaks
  • inline - Only needed width
  • inline-block - Inline with width/height
  • none - Hidden from layout
Positioning

Position elements on the page:

Position Types:

  • static - Default positioning
  • relative - Relative to normal position
  • absolute - Relative to parent
  • fixed - Relative to viewport
Positioning Offsets

Move positioned elements:

Offset Properties:

  • top - Distance from top
  • bottom - Distance from bottom
  • left - Distance from left
  • right - Distance from right
Z-Index and Stacking

Control element layering:

Z-Index:

  • Higher values appear on top
  • Works with positioned elements
  • Creates stacking context
Learning Outcomes
  • Use display property
  • Apply positioning
  • Control element stacking
  • Create custom layouts
