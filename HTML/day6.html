Day 6: CSS Basics & Selectors

What is CSS?

CSS (Cascading Style Sheets) is used to style and layout web pages:

CSS Controls:

  • Colors and backgrounds
  • Fonts and text styling
  • Page layout and spacing
  • Animations and effects
Ways to Apply CSS

Three methods to add CSS:

CSS Methods:

  • Inline - In HTML tag (not recommended)
  • Internal - In <style> tag
  • External - Separate .css file (best)
CSS Selectors

Selectors target HTML elements:

Selector Types:

  • Element: p { ... }
  • Class: .classname { ... }
  • ID: #idname { ... }
  • Universal: * { ... }
Specificity and Cascade

Understanding CSS priority:

Specificity Order:

  • ID selectors (highest)
  • Class and attribute selectors
  • Element selectors (lowest)
  • !important (overrides all)
Learning Outcomes
  • Understand CSS basics
  • Use CSS selectors
  • Apply CSS to HTML
  • Understand specificity
