Day 5: HTML Tables & Lists

HTML Tables

Tables organize data in rows and columns:

Table Elements:

  • <table> - Table container
  • <tr> - Table row
  • <td> - Table data cell
  • <th> - Table header cell
Table Structure

Organize tables sections:

Structural Elements:

  • <thead> - Table header section
  • <tbody> - Table body section
  • <tfoot> - Table footer section
  • <caption> - Table title
Ordered Lists

Numbered lists for sequential items:

Ordered List Elements:

  • <ol> - Ordered list container
  • <li> - List item
  • type attribute: 1, a, A, i, I
Unordered and Definition Lists

Other list types:

Other Lists:

  • <ul> - Unordered list (bullets)
  • <dl> - Definition list
  • <dt> - Definition term
  • <dd> - Definition description
Learning Outcomes
  • Create and structure tables
  • Use proper table markup
  • Build different types of lists
  • Nest lists properly
