Day 1: HTML Basics & Structure

What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create web pages. It provides the structure and content of websites.

HTML is used for:

  • Creating page structure
  • Organizing content
  • Adding text, images, and links
  • Creating forms
HTML Document Structure

Every HTML document has a standard structure:

Key Elements:

  • <!DOCTYPE html> - Declares document type
  • <html> - Root element
  • <head> - Contains metadata
  • <body> - Contains visible content
Basic HTML Tags

Here are the most common HTML tags:

Content Tags:

  • <h1> to <h6> for headings
  • <p> for paragraphs
  • <a> for links
  • <img> for images
HTML Attributes

Attributes provide additional information about HTML elements:

Common Attributes:

  • class - For CSS styling
  • id - Unique identifier
  • href - URL for links
  • src - Source for images
  • alt - Alternative text
Learning Outcomes
  • Understand HTML basics
  • Know document structure
  • Use common HTML tags
  • Apply HTML attributes
