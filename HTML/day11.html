Day 11: CSS Grid

What is CSS Grid?

Grid is a two-dimensional layout system:

Grid Basics:

  • display: grid - Enable grid
  • Two-dimensional layout
  • Rows and columns
  • Powerful alignment
Grid Tracks

define grid structure:

Properties:

  • grid-template-columns - Column sizes
  • grid-template-rows - Row sizes
  • grid-gap - Space between items
  • Units: px, %, fr (fraction)
Grid Areas

Named areas for layout:

Grid Areas:

  • grid-template-areas - Define layouts
  • grid-area - Place items
  • Visual layout definition
Grid Item Placement

Position and span items:

Properties:

  • grid-column - Span columns
  • grid-row - Span rows
  • justify-self - Horizontal alignment
  • align-self - Vertical alignment
Learning Outcomes
  • Create grid containers
  • Define grid tracks
  • Use grid areas
  • Place items in grids
