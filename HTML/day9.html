Day 9: CSS Flexbox

What is Flexbox?

Flexbox is a powerful layout system for arranging items:

Flexbox Basics:

  • display: flex - Enable flexbox
  • One-dimensional layout
  • Great for alignment
  • No need for floats
Flex Direction

Control item direction:

Direction Values:

  • row - Left to right (default)
  • column - Top to bottom
  • row-reverse - Right to left
  • column-reverse - Bottom to top
Justify and Align

Align items in containers:

Properties:

  • justify-content - Main axis alignment
  • align-items - Cross axis alignment
  • align-content - Multiple lines
  • Values: flex-start, center, flex-end, space-between
Flex Items

Control children items:

Item Properties:

  • flex-grow - Growth factor
  • flex-shrink - Shrink factor
  • flex-basis - Base size
  • flex - Shorthand
Learning Outcomes
  • Create flex containers
  • Use flex direction
  • Align items properly
  • Build flexible layouts
