Day 7: CSS Box Model

Understanding the Box Model

Every HTML element is a box with four layers:

Box Layers:

  • Content - The actual content
  • Padding - Space inside the border
  • Border - Edge of the box
  • Margin - Space outside the box
Margin Properties

Control space outside elements:

Margin Properties:

  • margin - All sides
  • margin-top, margin-bottom
  • margin-left, margin-right
  • Shorthand: margin: 10px 20px;
Padding and Border

Inner spacing and element edges:

Properties:

  • padding - Space inside border
  • border-width - Thickness
  • border-style - solid, dashed, dotted
  • border-color - Border color
Width and Height

Sizing and box-sizing property:

Sizing:

  • width - Element width
  • height - Element height
  • box-sizing: content-box (default)
  • box-sizing: border-box (includes padding)
Learning Outcomes
  • Understand the box model
  • Control margins and padding
  • Create borders
  • Manage element sizing
