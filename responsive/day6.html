Day 6: Responsive design with Tailwind

Tailwind uses a mobile-first breakpoint system. You write CSS for mobile screens first, then add breakpoint prefixes for larger screens. This ensures your site works on mobile by default.

  • sm: - Small screens (640px and up)
  • md: - Medium screens (768px and up)
  • lg: - Large screens (1024px and up)
  • xl: - Extra-large screens (1280px and up)
  • 2xl: - 2XL screens (1536px and up)
  • hover: - Mouse hover state
  • focus: - Focus state
  • active: - Active/clicked state
  • disabled: - Disabled state
  • group-hover: - Hover on parent

Responsive grid that stacks on mobile:

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
  • Always start with mobile designs
  • Use breakpoint prefixes to progressively enhance layouts
  • Test your designs on actual devices
  • Keep responsive behavior consistent throughout your app
