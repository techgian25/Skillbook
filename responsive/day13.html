Day 13: Utilities and helpers (Bootstrap)

Spacing Utilities

Bootstrap provides utility classes for margin and padding:

  • m-* - Margin on all sides
  • mt-3, mb-2 - Margin top/bottom
  • p-4 - Padding on all sides
  • ms-auto - Margin-start (auto = right side)
Display & Visibility
  • d-block, d-inline, d-flex - Display types
  • d-none - Hide element
  • d-sm-block - Responsive display
  • visibility-hidden - Hide but keep space
Text Utilities
  • text-center, text-start - Text alignment
  • text-uppercase, text-lowercase - Text transform
  • fw-bold, fs-5 - Font weight and size
  • text-muted - Muted text color
Utility Example

Using common utilities together:

<div class="d-flex justify-content-between align-items-center p-3 mb-4">
  <h3 class="text-center fw-bold">Title</h3>
  <span class="text-muted">12 items</span>
</div>
More Utilities
  • Opacity utilities for transparency
  • Float utilities for positioning
  • Overflow utilities for content overflow
  • Sizing utilities for width and height
