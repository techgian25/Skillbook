Day 1: Introduction to Bootstrap

What is Bootstrap?

Bootstrap is a popular open-source CSS framework developed by Twitter (now X) that helps developers create responsive, mobile-first websites quickly. It provides a collection of pre-built CSS classes, components, and JavaScript plugins that make web development faster and easier.

Bootstrap is used for:

  • Creating responsive layouts
  • Building reusable components
  • Styling forms and buttons
  • Adding JavaScript interactivity
Key Features

Bootstrap provides a comprehensive toolkit for modern web development:

Main Features:

  • Responsive Grid System - 12-column mobile-first layout
  • Pre-built Components - Buttons, forms, navigation, modals
  • Utility Classes - Quick styling without custom CSS
  • JavaScript Plugins - Interactive elements out of the box
  • Customizable - Variables for colors, fonts, spacing
How to Get Started

You can include Bootstrap in your project in several ways:

Installation Methods:

  • CDN: Add the Bootstrap CSS and JS links to your HTML
  • Download: Get compiled CSS and JS files from bootstrap.com
  • Package managers: Install via npm, yarn, or pnpm
  • Source: Import SCSS for full customization
Basic Example

Here's a simple example of Bootstrap button styling:

Bootstrap Button Code:

<button class="btn btn-secondary">Secondary Button</button>
