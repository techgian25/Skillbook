Day 4: Utility classes overview (Tailwind)

What are Utility Classes?

Utility classes are small, single-purpose CSS classes that do one thing well. Instead of creating custom classes like 'btn-primary', you compose classes to build your design directly in HTML.

Common Utility Classes

Tailwind provides utilities for every CSS property:

Utility Categories:

  • Spacing: p-4 (padding), m-2 (margin), gap-3 (gap)
  • Colors: bg-blue-500 (background), text-red-600 (text)
  • Typography: text-lg, font-bold, font-semibold
  • Display: flex, grid, block, inline-block
  • Sizing: w-full (width), h-32 (height)
Naming Convention

Tailwind class names follow a consistent and predictable pattern:

Class Structure:

  • Property: p (padding), m (margin), text, bg (background)
  • Size/Value: 1, 2, 4, 8, 16 (spacing scale)
  • Modifier: hover:, focus:, md:, lg: (for states/breakpoints)
Practical Examples

Real-world examples of combining utilities:

Common Patterns:

<button class="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-700">Button</button>
<div class="flex gap-4 p-6 bg-gray-50 rounded-lg">...</div>
Learning Outcomes
  • Understand the utility-first philosophy
  • Learn to read Tailwind class names
  • Combine utilities effectively
  • Build complex designs without custom CSS
