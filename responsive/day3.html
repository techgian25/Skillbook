Day 3: Grid system basics (Bootstrap)

Understanding Bootstrap's Grid System

Bootstrap's grid system is based on a 12-column layout that helps you create responsive designs. It uses containers, rows, and columns to structure your content across different screen sizes.

Key Components

The grid system consists of three main parts:

Grid Components:

  • Container: The outermost wrapper that centers content
  • Row: Horizontal groups of columns
  • Column: Content containers that span 1-12 columns
Basic Grid Classes

Bootstrap provides responsive classes for different breakpoints:

Column Classes:

  • col - Auto-sizing columns
  • col-* - Specific column spans (col-6 for half width)
  • col-sm-*, col-md-*, col-lg-* - Responsive breakpoints
Basic Example

Here's a simple 2-column layout:

Bootstrap Grid Code:

<div class="container">
  <div class="row">
    <div class="col-md-6">Column 1</div>
    <div class="col-md-6">Column 2</div>
  </div>
</div>
