Day 14: Responsive components (Tailwind)

Responsive Card Layout

Create cards that adapt to different screens using grid and flex:

  • 1 column on mobile
  • 2 columns on tablet
  • 3+ columns on desktop
Responsive Navigation
  • Hamburger menu on mobile using md:flex
  • Show full nav on desktop
  • Toggle menu visibility with JavaScript
  • Use hidden md:block for responsive display
Responsive Images
  • w-full - Responsive width
  • h-auto - Auto height maintains aspect ratio
  • object-cover - Fill container while maintaining ratio
  • aspect-video - Maintain aspect ratio
Component Example

Responsive card component:

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  <div class="bg-white p-4 rounded shadow">
    <img src="img.jpg" class="w-full h-48 object-cover">
    <h3 class="mt-2 font-bold">Card Title</h3>
  </div>
</div>
Component Tips
  • Test on actual devices, not just browser resizing
  • Use consistent spacing across breakpoints
  • Keep touch targets 44x44px minimum on mobile
  • Use semantic HTML for accessibility
