Day 5: Components – Buttons & Forms (Bootstrap)

Bootstrap Buttons

Bootstrap provides ready-made button styles with various color schemes and sizes. Each button type conveys different meanings and actions.

Button Styles:

  • btn btn-primary - Blue primary action button
  • btn btn-secondary - Gray secondary button
  • btn btn-success - Green success button
  • btn btn-danger - Red danger button
  • btn btn-warning - Yellow warning button
Button Sizes

Control button sizes with Bootstrap size classes:

Available Sizes:

  • btn btn-sm - Small button
  • btn - Default button
  • btn btn-lg - Large button
Form Elements

Bootstrap simplifies form styling with consistent classes:

Form Classes:

  • form-control - Standard input field styling
  • form-check - Checkbox and radio styling
  • form-select - Select dropdown styling
  • form-label - Label styling
  • form-text - Helper text
Basic Form Example

Here's a complete form structure with Bootstrap:

Contact Form:

<form>
  <div class="mb-3">
    <label class="form-label">Email</label>
    <input type="email" class="form-control">
  </div>
  <button type="submit" class="btn btn-primary">Submit</button>
</form>
Validation States
  • is-valid - Shows green validation state
  • is-invalid - Shows red validation state
  • valid-feedback - Success message display
  • invalid-feedback - Error message display
Learning Outcomes
  • Understand Bootstrap button variations
  • Use different button sizes and styles
  • Create styled form elements
  • Build complete forms with Bootstrap
