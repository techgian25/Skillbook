Day 10: Advanced layout with flex & grid (Tailwind)

Flexbox is perfect for one-dimensional layouts. Tailwind provides utilities for all flex properties:

  • flex - Create flex container
  • justify-between, justify-center - Horizontal alignment
  • items-center, items-start - Vertical alignment
  • flex-col - Stack items vertically

Grid is ideal for two-dimensional layouts:

  • grid - Create grid container
  • grid-cols-3 - 3 columns
  • grid-rows-2 - 2 rows
  • gap-4 - Space between items
  • flex-1 - Grow to fill space equally
  • flex-auto - Grow but maintain min content
  • flex-none - Don't grow or shrink
  • flex-grow and flex-shrink - Fine control

Flex header and grid content:

<div class="flex justify-between items-center">
  <h1>Header</h1>
  <nav class="gap-4 flex">...</nav>
</div>
<div class="grid grid-cols-3 gap-4">...</div>
  • Flex: Best for 1D layouts (rows or columns)
  • Grid: Best for 2D layouts (rows and columns)
  • Can combine flex and grid together
  • Flex is simpler, Grid is more powerful
