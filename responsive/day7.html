Day 7: Grid utilities & breakpoints (Bootstrap)

Bootstrap defines breakpoints for different device sizes:

  • XS (extra small): <576px - Mobile phones
  • SM (small): ≥576px - Landscape phones
  • MD (medium): ≥768px - Tablets
  • LG (large): ≥992px - Desktops
  • XL (extra large): ≥1200px - Large desktops
  • col-12 - Full width (1/12 * 12)
  • col-6 - Half width (1/12 * 6)
  • col-4 - One-third width (1/12 * 4)
  • col-3 - One-quarter width (1/12 * 3)
  • col-md-6 - Half width on medium+ screens
  • offset-3 - Move column 3 spaces right
  • row-cols-2 - Auto-fit 2 columns per row
  • justify-content-between - Space items apart
  • align-items-center - Vertically center items

Responsive layout that adapts to screen size:

<div class="row">
  <div class="col-12 col-md-6 col-lg-3">Item 1</div>
  <div class="col-12 col-md-6 col-lg-3">Item 2</div>
  <div class="col-12 col-md-6 col-lg-3">Item 3</div>
  <div class="col-12 col-md-6 col-lg-3">Item 4</div>
</div>
  • Always wrap columns in a row
  • Use responsive column classes for flexible layouts
  • Combine offset classes to center content
  • Test breakpoints on real devices
