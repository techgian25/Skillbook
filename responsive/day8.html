Day 8: Customizing with config (Tailwind)

The config file is where you customize Tailwind CSS. It controls colors, spacing, fonts, and more. You can extend the default theme or override it completely.

  • Colors - Define your brand palette
  • Typography - Set font families and sizes
  • Spacing - Customize the spacing scale
  • Breakpoints - Define custom responsive breakpoints
  • Shadows - Create custom shadow values

Extend: Add custom colors while keeping defaults

Override: Replace the entire theme section (loses all defaults)

Sample configuration:

module.exports = { theme: { extend: { colors: { 'brand-blue': '#0066cc' } } } }
  • Match your brand identity
  • Maintain consistency across projects
  • Reduce custom CSS code
  • Improve team collaboration with shared configs
