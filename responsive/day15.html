Day 15: Custom themes & SCSS (Bootstrap)

Understanding Bootstrap SCSS

Bootstrap is written in SCSS (Sass), which allows for variables, mixins, and functions. You can customize Bootstrap by overriding SCSS variables before importing Bootstrap.

Customizable Variables
  • Color variables ($primary, $success, etc.)
  • Typography variables ($font-family-base, $font-size-base)
  • Spacing variables ($spacer, scales from that)
  • Breakpoint variables for responsive design
SCSS Mixins

Bootstrap provides helpful SCSS mixins:

  • @mixin media-breakpoint-up($breakpoint) - Media queries
  • @mixin clearfix() - Clearfix hack
  • @mixin visually-hidden() - Hide from visual but keep for screen readers
Custom Theme Example

Override Bootstrap variables:

// Before importing Bootstrap
$primary: #0066cc;
$secondary: #666666;
$danger: #ff4444;
$font-family-base: 'Roboto', sans-serif;

@import 'bootstrap/scss/bootstrap';
Theme Best Practices
  • Override variables, don't modify Bootstrap source
  • Document your color palette and conventions
  • Use consistent naming for custom variables
  • Test theme changes across all components
  • Keep brand colors centralized
