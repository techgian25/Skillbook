Day 11: Forms & validation (Bootstrap)

Bootstrap forms use consistent markup and classes:

  • form-group - Wrapper for form elements
  • form-control - Input field styling
  • form-text - Helper text below inputs
  • was-validated - Show validation states
  • Valid: is-valid class shows green success state
  • Invalid: is-invalid class shows red error state
  • Feedback: Use valid-feedback or invalid-feedback
  • Tooltips: Show validation inline with tooltips
  • Text input
  • Email input
  • Password input
  • Number input
  • Textarea
  • Checkboxes and radios
  • Select dropdowns

Complete contact form with validation:

<form class="needs-validation">
  <div class="form-group">
    <label>Name</label>
    <input type="text" class="form-control is-invalid">
    <div class="invalid-feedback">Required</div>
  </div>
</form>

Bootstrap provides built-in form validation JavaScript. Use the needs-validation class on your form and check validity before submission.
