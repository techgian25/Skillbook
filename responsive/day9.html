Day 9: Components – Modals & Navbars (Bootstrap)

Navbars are responsive navigation headers for your site or app. They include support for branding, navigation, and other components.

  • navbar - Main navbar container
  • navbar-expand-lg - When to expand the navbar
  • navbar-light or navbar-dark - Navbar color scheme
  • nav-link - Navigation links

Modals are dialog boxes/popups that overlay the main content. Perfect for alerts, confirmations, and forms.

  • modal - Main modal container
  • modal-dialog - Modal dialog wrapper
  • modal-content - Modal content area
  • modal-header, modal-body, modal-footer
  • Scrollable modals for large content
  • Centered modals (vertically)
  • modal-lg, modal-sm - Size variants
  • Backdrop options (show/hide backdrop)

Basic navbar structure:

<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container">
    <a class="navbar-brand">Logo</a>
    <button class="navbar-toggler">...</button>
    <div class="collapse navbar-collapse">...</div>
  </div>
</nav>
  • Use modals for important user interactions
  • Keep navbar content minimal on mobile
  • Always provide a close button for modals
  • Test modals on different screen sizes
