Day 7: Conditional Rendering

What is Conditional Rendering?

Conditional rendering in React allows components to display different UI based on certain conditions. It works similar to JavaScript conditions.

  • Show different UI based on conditions
  • Use JavaScript logic inside JSX
  • Improve dynamic UI behavior
  • Common in authentication and dashboards
Conditional Rendering Example 
function App(){

 const isLoggedIn = true;

 return(
   <div>
     {isLoggedIn ? <h1>Welcome User</h1> : <h1>Please Login</h1>}
   </div>
 )

}
Ways to Do Conditional Rendering
  • if / else statements
  • Ternary operator
  • Logical AND (&&)
  • Switch statements
Outcome
  • Understand conditional rendering
  • Use ternary operator in JSX
  • Render UI dynamically
  • Improve user experience
