Day 8: Lists & Keys

What are Lists in React?

Lists allow you to display multiple items dynamically in React. Usually we use the map() function to render lists.

  • Render dynamic data
  • Use arrays to generate UI
  • Common in dashboards and tables
  • Improves UI scalability
Lists Example 
const fruits = ["Apple","Banana","Orange"]

function App(){

 return(
   <ul>
     {fruits.map((fruit) =>
        <li>{fruit}</li>
     )}
   </ul>
 )

}
What are Keys?

Keys are special attributes used in React lists to identify elements uniquely. They help React efficiently update and re-render lists. 

{items.map((item) =>
  <li key={item.id}>{item.name}</li>
)}
Outcome
  • Render lists using map()
  • Understand React keys
  • Improve performance with unique keys
  • Create dynamic UI lists
