Day 4: React Props

What are Props?

Props (short for properties) are used to pass data from one component to another. Usually they are passed from a parent component to a child component.

  • Props allow data sharing between components
  • Props are read-only
  • Props make components reusable
  • Passed as attributes in JSX
Props Example 
function Welcome(props){
 return <h1>Hello {props.name}</h1>
}

<Welcome name="React" />
Important Props Rules
  • Props are immutable (cannot change)
  • Props come from parent components
  • Props are passed using attributes
  • Props improve component reusability
Outcome
  • Understand how props work
  • Pass data between components
  • Create reusable components
  • Follow props best practices
