Day 13: Custom Hooks

What are Custom Hooks?

Custom Hooks are JavaScript functions that allow you to reuse React logic across multiple components. They help keep code clean, reusable, and easier to maintain.

  • Reuse logic between components
  • Keep components cleaner
  • Follow React hook rules
  • Start with the word "use"
Custom Hook Example 
import { useState } from "react";

function useCounter(){

 const [count,setCount] = useState(0);

 function increment(){
   setCount(count + 1)
 }

 return {count,increment}

}
Using the Custom Hook 
function App(){

 const {count,increment} = useCounter();

 return(
  <button onClick={increment}>
    {count}
  </button>
 )

}
Outcome
  • Understand custom hooks
  • Reuse React logic
  • Write cleaner components
  • Improve code maintainability
