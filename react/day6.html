Day 6: React Events

What are Events in React?

Events in React allow applications to respond to user interactions such as clicks, typing in inputs, submitting forms, and hovering elements.

  • Handle user interactions
  • Trigger functions on actions
  • Work similar to JavaScript DOM events
  • Written in camelCase
Event Example 
function App(){

 function handleClick(){
   alert("Button clicked")
 }

 return(
   <button onClick={handleClick}>
      Click Me
   </button>
 )

}
Common React Events
  • onClick
  • onChange
  • onSubmit
  • onMouseOver
  • onKeyDown
Outcome
  • Understand React events
  • Handle user interactions
  • Create event handler functions
  • Build interactive UI
