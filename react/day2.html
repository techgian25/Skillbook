Day 2: JSX in React

What is JSX?

JSX stands for JavaScript XML. It allows developers to write HTML-like syntax inside JavaScript. React uses JSX to describe what the UI should look like.

  • Write HTML inside JavaScript
  • Makes UI code easier to read
  • Converted to JavaScript using Babel
JSX Example

Example of JSX syntax: 

const element = <h1>Hello React</h1>;
JSX Rules
  • Only one parent element
  • Use className instead of class
  • Use camelCase for attributes
  • JavaScript expressions inside { }
JSX Expressions

You can use JavaScript expressions inside JSX using curly braces. 

const name = "React";
const element = <h1>Hello {name}</h1>;
Outcome
  • Understand what JSX is
  • Write HTML inside JavaScript
  • Learn JSX syntax rules
  • Use JavaScript expressions in JSX
