Day 12: React Context API

What is Context API?

The Context API is used to share data globally between React components without passing props manually through every level of the component tree.

  • Global state management
  • Avoid prop drilling
  • Share data across components
  • Common for themes, auth, user data
Creating Context 
import { createContext } from "react";

const UserContext = createContext();
Using Context Provider 
<UserContext.Provider value="John">
   <App />
</UserContext.Provider>
Using useContext Hook 
import { useContext } from "react";

const user = useContext(UserContext);
Outcome
  • Understand global state sharing
  • Avoid prop drilling
  • Use Context Provider
  • Access data using useContext
