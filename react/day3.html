Day 3: React Components

What are React Components?

Components are reusable building blocks used to create user interfaces in React. Each component returns JSX that describes part of the UI.

  • Reusable UI pieces
  • Make code modular
  • Improve maintainability
  • Allow separation of concerns
Types of React Components
  • Functional Components (Most common)
  • Class Components (Older approach)
Component Example 
function Welcome(){
 return <h1>Hello React</h1>
}
Outcome
  • Understand React components
  • Create functional components
  • Reuse UI components
  • Organize React applications
