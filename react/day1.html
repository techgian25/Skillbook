Day 1: Introduction to React

What is React?

React is a JavaScript library used to build fast and interactive user interfaces for web applications.

With React:

  • Create reusable UI components
  • Build single page applications
  • Manage UI state efficiently
  • Update UI quickly using Virtual DOM
Where React Runs

React applications mainly run in web browsers.

  • Chrome
  • Firefox
  • Edge
  • Safari
How to Create a React App

You can create a React application using the following steps:

  • Install Node.js
  • Run: npx create-react-app myApp
  • Navigate: cd myApp
  • Start server: npm start
React Console

console.log("Hello React");
