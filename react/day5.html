Day 5: React State

What is State?

State is used to store dynamic data inside a React component. When state changes, React automatically re-renders the UI.

  • State stores component data
  • State can change over time
  • Changing state updates the UI
  • State is commonly used with hooks
useState Hook

React provides the useState hook to manage state in functional components. 

import { useState } from "react";

function Counter() {
 const [count, setCount] = useState(0);

 return (
   <button onClick={() => setCount(count + 1)}>
     {count}
   </button>
 );
}
Important State Rules
  • State must be updated using the setter function
  • Never modify state directly
  • Updating state triggers re-render
  • Each component manages its own state
Outcome
  • Understand React state
  • Use the useState hook
  • Update UI dynamically
  • Follow state management rules
