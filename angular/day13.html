Day 13: Angular State Management

What is State?

State refers to the data used in an application. Managing state means controlling how data is stored, updated, and shared across components.

  • Store application data
  • Share data between components
  • Update UI dynamically
  • Maintain data consistency
State Management Methods
  • Using Services (Simple apps)
  • Using RxJS BehaviorSubject
  • Using NgRx (Advanced apps)
Service State Example 
private data = new BehaviorSubject("Hello");

currentData$ = this.data.asObservable();

 this.data.next(value);
}
NgRx (Advanced State Management)

NgRx is a Redux-based state management library for Angular. It helps manage complex application state.

  • Store
  • Actions
  • Reducers
  • Effects
Outcome
  • Understand application state
  • Manage data using services
  • Use RxJS for state updates
  • Learn basics of NgRx
