Day 12: Angular Observables (RxJS)

What are Observables?

Observables are used to handle asynchronous data streams in Angular. They are part of RxJS (Reactive Extensions for JavaScript).

  • Handle async operations
  • Work with streams of data
  • Used with HTTP calls
  • Support multiple values over time
Observable Example 
import { Observable } from 'rxjs';

const obs = new Observable(observer => {
 observer.next("Hello");
 observer.next("Angular");
});
Subscribe to Observable

To receive data from an Observable, you must subscribe to it. 

obs.subscribe(data => {
 console.log(data);
});
RxJS Operators

Operators help transform and manipulate data streams.

  • map
  • filter
  • tap
  • mergeMap
Outcome
  • Understand Observables
  • Use subscribe method
  • Work with async data
  • Use RxJS operators
