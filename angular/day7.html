Day 7: Services & Dependency Injection

What are Angular Services?

Services are used to share data and business logic across components. They help keep components clean and reusable.

  • Share data between components
  • Handle API calls
  • Contain business logic
  • Improve code reusability
Service Example 
import { Injectable } from '@angular/core';

@Injectable({
 providedIn: 'root'
})

export class DataService {

 getData(){
  return ["Angular","React","Vue"];
 }

}
What is Dependency Injection?

Dependency Injection (DI) is a design pattern used to provide services to components. Angular automatically injects services where needed.

  • Reduces code dependency
  • Improves testability
  • Promotes reusable services
Injecting Service into Component 
constructor(private dataService: DataService){}

ngOnInit(){
 this.data = this.dataService.getData();
}
