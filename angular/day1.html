Day 1: Introduction to Angular

What is Angular?

Angular is a TypeScript-based front-end framework used to build modern, scalable web applications.

With Angular:

  • Build single page applications (SPA)
  • Create reusable components
  • Use powerful dependency injection
  • Develop large enterprise applications
Where Angular Runs

Angular applications mainly run inside modern web browsers.

  • Chrome
  • Firefox
  • Edge
  • Safari
How to Create Angular App

Angular applications are created using Angular CLI. 

npm install -g @angular/cli

ng new myApp

cd myApp

ng serve
Angular Console

You can check Angular logs using browser developer console. 

console.log("Hello Angular");
Outcome
  • Understand Angular framework
  • Know where Angular runs
  • Learn Angular CLI basics
  • Create your first Angular project
