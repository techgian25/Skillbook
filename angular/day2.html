Day 2: Angular Architecture

What is Angular Architecture?

Angular architecture defines the structure used to build Angular applications. It organizes the application using modules, components, templates, and services.

Key Angular Architecture Parts:

  • Modules
  • Components
  • Templates
  • Services
  • Dependency Injection
Angular Modules

Modules organize Angular applications into cohesive blocks of functionality. Every Angular app has at least one module called AppModule. 

@NgModule({
 declarations: [AppComponent],
 imports: [BrowserModule],
 bootstrap: [AppComponent]
})
export class AppModule {}
Angular Components

Components control views in Angular applications. Each component consists of a template, class, and metadata. 

@Component({
 selector: 'app-root',
 template: '<h1>Hello Angular</h1>'
})
export class AppComponent {}
Outcome

  • Build scalable Angular apps
