Day 6: Angular Pipes

What are Angular Pipes?

Pipes are used to transform data in Angular templates. They help format values like text, dates, currency, and more.

Common Uses:

  • Format dates
  • Transform text
  • Display currency
  • Filter or modify data
Built-in Pipes
  • uppercase
  • lowercase
  • date
  • currency
  • json
{{ name | uppercase }}
{{ today | date }}
{{ price | currency }}
Custom Pipes

You can create your own pipes using Angular CLI. 

ng generate pipe myPipe
Chaining Pipes

Multiple pipes can be used together to transform data. 

{{ name | uppercase | slice:0:5 }}
