Day 10: Angular HTTP Client

What is Angular HTTP Client?

Angular HTTP Client is used to communicate with backend servers. It allows sending HTTP requests like GET, POST, PUT, and DELETE.

  • Fetch data from APIs
  • Send data to server
  • Handle responses
  • Work with REST APIs
Import HTTP Module 
import { HttpClientModule } from '@angular/common/http';

@NgModule({
 imports: [HttpClientModule]
})
GET Request Example 
constructor(private http: HttpClient){}

this.http.get('https://api.example.com/data')
.subscribe(data => {
 console.log(data);
});
POST Request Example 
this.http.post('https://api.example.com/data', {
 name: "Angular"
})
.subscribe(res => console.log(res));
Outcome
  • Understand Angular HTTP Client
  • Make API calls
  • Handle server responses
  • Work with REST APIs
