Day 14: Angular Performance Optimization (Lazy Loading)

What is Performance Optimization?

Performance optimization improves the speed and efficiency of an Angular application. It ensures faster loading and better user experience.

  • Improve app speed
  • Reduce load time
  • Enhance user experience
  • Optimize resource usage
Change Detection Strategy

Angular uses change detection to update the UI. Using OnPush strategy improves performance. 

@Component({
 changeDetection: ChangeDetectionStrategy.OnPush
})
Lazy Loading

Lazy loading loads modules only when needed. This reduces initial bundle size.

  • Faster app startup
  • Better performance
  • Load modules on demand
trackBy in ngFor

trackBy helps Angular identify items efficiently in lists. It prevents unnecessary DOM updates.
